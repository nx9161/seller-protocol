# Per-SKU P&L

Maintained by Finance Counsel. One block per SKU.

## Template
- **SKU / launch date**
- **Landed cost:** unit + tooling amortized + freight + duties +
  insurance + warehousing allocation
- **Amazon fees:** referral + FBA per unit
- **Ad spend / TACoS**
- **Net margin per unit and total; break-even units**
- **Verdict:** scale / hold / kill — with date
