# Playbook: Fix Listing

For suppressed listings, hijackers, account-health warnings, and
underperforming listings.

1. **Diagnose (Amazon FBA Specialist).** Pull the exact Amazon notice /
   metric. Classify: policy violation, hijacker/counterfeit, listing
   error, performance.
2. **Brief (Knowledge Wizard).** Current Amazon policy on the issue;
   simplest compliant fix path.
3. **Legal check (Trade Lawyer)** if IP, counterfeit, or compliance is
   involved.
4. **Fix (Amazon Services Expert).** Rewrite/repair the listing, file
   the appeal or report with evidence.
5. **Verify.** Listing live and healthy; account health green. Journal
   the run; record the lesson in `memory/`.

## Rules
- Never use black-hat recovery tactics (fake reviews, rank
  manipulation) — bannable, and the office doesn't do it.
- If the fix needs money (e.g., test buys for hijacker evidence),
  owner approval first.
