# Office Handbook

Welcome to the office. This folder is the office's memory and rulebook.

- **HOUSE_RULES.md** — binding rules for every employee.
- **PLAN.md** — the founding plan.
- **staff/** — employee profiles. Hiring someone new = adding a file here.
  15 roles in 7 divisions:
  - *Leadership:* mercer (Chief Operator)
  - *Sourcing & Supply Chain:* china-sourcing-expert, vendor-picker
  - *Logistics & Warehousing:* shipping-expert, warehouse-expert
  - *Marketplaces:* amazon-fba-specialist, amazon-services-expert,
    product-suggester
  - *Digital Storefront:* website-expert, shopify-expert, ui-designer
  - *Legal & Finance:* trade-lawyer, finance-counsel
  - *Intelligence:* prompt-writer, knowledge-wizard
- **playbooks/** — repeatable procedures, run by spawning one subagent
  per step: `intake`, `war-room`, `launch-product`, `fix-listing`,
  `skill-hunt`.
- **skills/** — capabilities the Knowledge Wizard hunted across the
  internet, vetted, and installed (`office/skills/<slug>/SKILL.md`).
- **scripts/** — automation helpers.
- **log/decisions.md** — every significant decision, dated.
- **log/runs/** — journal entries for each task run.

## Giving the office work
Tell Mercer in chat, or open a GitHub Issue describing what you want.
Attach screenshots or voice notes — the intake procedure handles all
three. Any product launch, inventory purchase, or freight booking goes
through the War Room first. No money moves without the owner's explicit
approval.
